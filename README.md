## Sunumların kaynağı

İşletim sistemlerine giriş ve süreçler konularındaki kuramsal slaytlar, Abraham Silberschatz, Peter B. Galvin ve Greg Gagne’nin *Operating System Concepts* (10. baskı, 2018) kitabına ait sunumlardan yararlanır. Terminal laboratuvarı ve Bike Sharing uygulaması gibi ders sunumları, Linux komutlarını uygulamalı örneklerle ele alır.

## Kaynak kitaplar

| Kaynak | Hangi konularda kullanabilirsiniz? |
| --- | --- |
| Brian Ward, *How Linux Works: What Every Superuser Should Know*, 3. baskı, No Starch Press, 2021. | Linux’un çalışma mantığı, çekirdek ve kullanıcı alanı, dosya sistemleri, süreç izleme ve ağlar. |
| William Shotts, *The Linux Command Line: A Complete Introduction*, 3. baskı, No Starch Press, 2026. | Terminal komutları, dosya işlemleri, izinler, yönlendirme ve boru hatları. |
| Lewis Finan, *Linux Guide for Beginners*, 2024. | Linux dağıtımları, terminal ve temel komutlar üzerine başlangıç düzeyinde ek okuma. |
